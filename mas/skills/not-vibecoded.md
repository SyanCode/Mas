# Not vibecoded

A vibecoded site is recognised in seconds: it looks like every other AI output and says nothing specific. The rule
that fixes almost everything: **every element must be justified by this business, this audience and this content**.
If the element could be pasted on any other site unchanged, rewrite it or remove it.

Run `polish_report` on the repository first: it finds the mechanical tells (placeholders, scaffold leftovers, buzzwords,
emoji icons, fake numbers, dead links, missing 404/favicon). Then fix what the report cannot see, with the lists below.
Load `design-craft` and `copywriting` for the details.

## Design tells → what to do instead

- Purple/indigo-to-pink gradients, gradient text, glowing blobs, glassmorphism everywhere → one brand colour used with
  restraint on neutrals tinted toward it; gradients only if the brand has them.
- Centered hero + 3 identical feature cards with an icon each + testimonial carousel + pricing table + CTA band → build
  the page from the content: what the visitor needs first, then proof, then action. Vary section layouts; use the
  real product (screenshots, photos) as the hero.
- Emoji as icons (🚀 ✨ 💡 in headings, buttons, bullet lists) → one consistent icon set (Lucide, Phosphor, Heroicons)
  at one stroke width, or no icons at all.
- Every corner `rounded-2xl`, every block a card with a shadow → pick one radius scale and one elevation scale; most
  content does not need a card.
- Inter/system font with no hierarchy → a deliberate type pairing and a modular scale (see design-craft).
- Stock 3D illustrations, abstract AI images, fake dashboards → real photos of the place, people and product; if none
  exist yet, a clear placeholder and a note for the person, never a fake.
- Dark mode toggle, animated counters, parallax and particles added "because" → only what serves the visitor.

## Copy tells → what to do instead

- "Unlock / elevate / supercharge / seamless / cutting-edge / revolutionize / empower / next level / in today's
  fast-paced world / harness the power" → concrete nouns and verbs from the business: what it does, for whom, where,
  at what price, by when.
- Headlines that promise everything ("The all-in-one platform for your success") → the specific outcome ("Fresh
  sourdough every morning, 7 rue Mercière, Lyon").
- Invented proof ("10,000+ happy customers", 5-star testimonials from "Sarah J.", "Trusted by" fake logos, "99.9%") →
  only real figures, real reviews with consent, real client logos. Otherwise leave the section out.
- Lorem ipsum, "Your Company", "John Doe", "123 Main Street", `example.com`, "© 2023" → real data, or a visible
  placeholder `[TO FILL: opening hours]` reported to the person.
- Em-dash chains, triplets everywhere ("fast, simple and powerful"), every sentence ending with an exclamation mark →
  plain sentences of varied length.
- English leftovers on a French site (or the reverse), mixed tutoiement/vouvoiement → one language, one register.

## Code and product tells → what to do instead

- Default scaffold: title "Vite + React" / "Create Next App", `vite.svg` / `next.svg` favicon, the bootstrap README,
  `App.css` demo styles, unused template pages → remove them; real title, favicon set, README that explains the project.
- `href="#"` links and buttons that do nothing, forms that submit nowhere → every control works or is removed.
- No 404 page, no loading/empty/error states, no focus styles, no form validation messages → add them (see
  code-quality and accessibility).
- `console.log`, commented-out blocks, `TODO`, unused dependencies and files → clean them.
- No favicon, no Open Graph image, no legal pages, no cookie consent when trackers exist → see launch-checklist and
  the compliance tools.
- Everything in one 800-line component, inline styles mixed with Tailwind and CSS modules → one styling approach,
  components split by responsibility, consistent names.

## Before you finish

Read the page as a visitor who knows this business: would they recognise it, trust it, find what they came for in
5 seconds? If one section is still generic, it is not done.
